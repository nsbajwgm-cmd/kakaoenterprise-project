# 문서 입력과 반복 분석 루프

FATF, ACAMS, TPAC 또는 유사한 AML·가상자산·무역금융 문서를 반복 입력으로 받아 같은 증거 규칙으로 보고서와 대본을 만드는 절차다.

## 입력 기록

매 실행에서 아래 정보를 분석 기록에만 남긴다. 원본 파일은 수정하지 않는다.

| 항목 | 기록 원칙 |
|---|---|
| 원본 | 제목, 파일명 또는 URL, 발행자, 문서 형식, 발행일, 페이지 수, 접근일 |
| 문서 주장 | 직접 확인한 문장 또는 충실한 요약과 페이지·단락·타임스탬프 |
| 공개 근거 | ECOS·DART·기관 공식자료의 URL, 조회일, 수치·단위·기준시점 |
| 분석 가설 | `분석 가설`로 별도 표기하고 반증 자료를 함께 기록 |
| 식별자 | corp_code, 종목코드, 확인된 법인명. 없으면 `DART 연계 미확인` |

## 반복 루프

1. 문서 등록과 출처 고정
2. 위험 논지·국제 전이 경로·통제 공백 추출
3. 식별자 게이트 적용
4. 관련 ECOS 지표의 공식 값과 한계 기록
5. 식별자가 있을 때만 DART 관련 공시 확인
6. 위험 논지별 협업 카드 생성
7. 보고서·대본 작성 및 렌더링 검수

## 협업 카드 최소 형식

| 문서/사례 위험 논지 | 한은·ECOS 거시 트리거 | FIU·금감원/DART 게이트 | CAMS 확인 질문 | 반증 후보 | 상태 |
|---|---|---|---|---|---|
| 원문 위치를 가진 주장 또는 관찰 사실 | 지표명·기준시점·제한 | 식별된 공시 또는 `DART 연계 미확인` | 계약·상대방·지갑 통제·자금원천 등 | 정상 사업·환율·계절성·계약 | 확인됨 / 정합성 검토 필요 / 연계 미확인 |

## 반복 실행 성공 기준

새 파일마다 원문 주장·공개근거·분석가 가설이 분리되고, 기업 식별자가 없을 때 임의 DART 연결 없이 `연계 미확인`을 남기며, 보고서와 대본이 같은 근거와 한계를 사용하면 성공이다.
