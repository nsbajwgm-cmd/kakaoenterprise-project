# 보고서·설명대본 형식

## 보고서 기본 구조

1. 목적·범위·원본 보존 고지
2. 입력 문서 또는 사례의 핵심 위험 논지
3. 국제경제·금융안정 전이 경로
4. 한국은행 관점: ECOS 점검 지표와 한계
5. FIU·금융감독원 관점: 감독 질문과 DART 공개공시 게이트
6. 한은–금감원–FIU 협업 카드와 CAMS 산출물
7. 우선순위, 반증 시나리오, 데이터 공백 및 비결론

문서 기반 보고서에는 인용 위치를, 사례 기반 보고서에는 관찰 사실의 근거를 남긴다. 특정 기업을 식별할 수 없으면 DART 공시 범주만 제시한다.

## 설명대본

본문 뒤 부록으로 5–10분 대본을 만든다. 시간 구간별로 다음 흐름을 사용한다.

1. 문제와 분석 경계
2. 문서·사례에서 직접 확인된 위험
3. 국제경제·금융안정 전이 경로
4. 한은, FIU, 금융감독원의 역할 구분
5. 협업 카드와 CAMS 확인 질문
6. 이번 결과의 한계와 다음 입력 단계

대본은 실제 공동조사·비공개 정보공유·STR 판단을 수행하거나 약속하는 표현을 쓰지 않는다. 영상 제작이 필요하면 이 대본을 NotebookLM 등 별도 영상 도구의 입력으로 사용한다.

## 최종 검수

- 원본 파일과 원문 메타데이터를 바꾸지 않았는가?
- 모든 핵심 주장에 출처 또는 위치가 있는가?
- ECOS 수치에 단위·기준시점·공식 출처가 있는가?
- DART 연결이 검증 가능한 식별자에만 근거하는가?
- 보고서와 대본의 사실·가설·한계가 일치하는가?
- 결과 문서의 표·한글·인용·쪽번호를 렌더링으로 확인했는가?
